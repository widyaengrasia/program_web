Foto Dan Video pada halaman web

Halaman ini menyajikan contoh penggunaan foto dan video pada halaman web

1. Menampilkan Foto

Contoh menampilkan foto pada halaman web menggunakan tag <img>

2. Menampilkan Foto dengan ukuran

ukuran pada foto bisa diatur menggunakan atribut width dan height

3. Menampilkan foto dengan link

foto bisa dijadikan link dengan menambahkan tag link, silahkan klik foto berikut:

4. Menampilkan Video

Video dapat ditampilkan pada halaman web menggunakan tag <video>
